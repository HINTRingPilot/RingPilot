
# 스마트링 기반 침대용 스마트폰 원격 조작기

## 1. 프로젝트 개요

침대에 누운 상태에서 거치대에 고정된 Android 스마트폰을 **손을 뻗지 않고 조작할 수 있는 오른손 검지 착용형 스마트링 리모컨**을 제작한다.

범용 스마트링이나 하루 종일 착용하는 웨어러블이 아니라, **유튜브·쇼츠·웹툰·웹페이지 등을 침대에서 볼 때 잠깐 사용하는 전용 입력장치**를 목표로 한다.

따라서 방수, 수영 대응, 수일간의 연속 작동보다는 다음을 우선한다.

**착용감 → 조작성 → 반응성 → 소형화 → 충분한 사용시간**

---

# 2. 핵심 사용 방식

스마트링에는 두 가지 입력 방식을 사용한다.

### ① 엄지 스틱 조작

오른손 검지에 낀 반지의 **엄지 방향 측면**에 4방향 + 중앙 클릭 스틱을 배치한다.

| 입력    | 기능             |
| ----- | -------------- |
| ↑     | 마우스 포인터 위 이동   |
| ↓     | 마우스 포인터 아래 이동  |
| ←     | 마우스 포인터 왼쪽 이동  |
| →     | 마우스 포인터 오른쪽 이동 |
| 중앙 누름 | 마우스 왼쪽 클릭      |

Android에는 **BLE HID Mouse**로 전달하여 일반 Bluetooth 마우스처럼 사용한다. Android의 HID 계층은 Bluetooth를 통해 연결된 마우스 등의 HID 입력장치를 지원한다. ([Android Developers][2])

초기에는 포인터 가속 기능 없이 일정 속도로 이동시키며, 실제 사용 후 필요할 경우 조정한다.

### ② 손가락 제스처

검지 자체를 위·아래·좌·우 등으로 움직이면 반지의 6축 IMU가 움직임을 측정한다.

XIAO 내부의 nRF52840 MCU에서 TinyML 모델을 실행하여 다음과 같이 분류한다.

```text
검지 움직임
   ↓
가속도 XYZ + 자이로 XYZ
   ↓
TinyML
   ↓
LEFT / RIGHT / UP / DOWN / IDLE
```

예상 활용은:

* 위/아래 → 쇼츠 전환 또는 스크롤
* 좌/우 → 웹툰·전자책 페이지 넘김

이다.

즉 프로젝트의 기본 UX는:

> **정밀 조작은 엄지 스틱, 반복적인 큰 화면 조작은 손가락 제스처**

로 역할을 분리한다.

# 3. 전체 시스템 구조

```text
                    SMART RING

      ┌─────────────────────────┐
      │                         │
      │      6축 IMU            │
      │         ↓               │
      │      TinyML             │
      │         ↓               │
      │      nRF52840           │
      │       ↙     ↘           │
      │    BLE HID   Custom BLE │
      │       ↑                 │
      │   4방향 스틱             │
      └────────┬────────────────┘
               │ BLE
               ▼
            Android
          ↙           ↘
    Mouse Pointer   Companion App
                       ↓
               AccessibilityService
                       ↓
                 Swipe / Scroll
```

스틱 입력은 Android 시스템이 직접 처리하는 **BLE HID Mouse** 방식으로 구현한다.

AI 제스처는 별도의 **Custom GATT Service**로 Android companion app에 전달하고, 앱에서 AccessibilityService를 사용하여 실제 화면 스와이프를 발생시키는 방식을 우선한다.

Android의 `AccessibilityService.dispatchGesture()`는 지정한 제스처를 사용자 터치처럼 터치스크린에 전달할 수 있다. ([Android Developers][3])

# 4. 현재 개발용 하드웨어

## XIAO nRF52840 Sense Pre-Soldered

현재 **Pre-Soldered 버전을 이미 주문한 상태**다.

공식 SKU:

**102010632**

XIAO nRF52840 Sense에는 다음이 이미 포함되어 있다.

| 구성        | 내용                   |
| --------- | -------------------- |
| MCU       | Nordic nRF52840      |
| CPU       | ARM Cortex-M4F 64MHz |
| RAM       | 256KB                |
| MCU Flash | 1MB                  |
| 추가 Flash  | 2MB                  |
| 통신        | Bluetooth            |
| 센서        | LSM6DS3TR-C 6축 IMU   |
| 충전        | Li-ion/Li-Po 충전회로    |
| 포트        | USB-C                |
| 크기        | 약 **21 × 17.8mm**    |

Seeed 공식 문서에서도 Sense 모델의 LSM6DS3TR-C IMU, 온보드 BLE 안테나, 배터리 충전 기능과 21×17.8mm 크기를 명시한다. ([Seeed Studio Wiki][4])

Pre-Soldered 버전은 핀헤더가 이미 납땜되어 있으므로 **개발 단계에서는 점퍼 케이블을 그냥 꽂아 사용할 수 있다.**

# 5. 개발용 방향 스위치

최종 SKRH를 처음부터 납땜하지 않고, 개발 단계에서는:

**Seeed Grove - 5-Way Switch [111020048]**

를 사용한다.

여기서 5-Way라는 것은:

**상 / 하 / 좌 / 우 + 중앙 클릭**

을 의미한다.

Grove 모듈은 이미 스위치와 제어회로가 PCB에 실장돼 있고 I²C 방식으로 통신한다.

공식 사양:

| 항목    | 사양             |
| ----- | -------------- |
| 입력    | 4방향 + 중앙 클릭    |
| 전압    | **3.3V / 5V**  |
| 통신    | I²C            |
| 기본 주소 | `0x03`         |
| 크기    | 40 × 20 × 10mm |
| 무게    | 4.1g           |

따라서 XIAO의 3.3V 출력으로 직접 구동해도 된다. ([Seeed Studio Wiki][5])

---

# 6. 개발용 케이블 연결

Grove 모듈과 Pre-Soldered XIAO 사이에는:

**Grove - 4 pin Female Jumper to Grove 4 pin Conversion Cable [110990028]**

을 사용한다.

한쪽은 Grove 커넥터, 반대쪽은 **2.54mm Female 점퍼 소켓**으로 되어 있어 XIAO의 Male 핀헤더에 직접 꽂을 수 있다. 공식 제품 역시 2.54mm 핀헤더 호환을 명시한다. ([Seeed Studio][6])

연결은 다음과 같다.

| 케이블 | Grove 역할 | XIAO         |
| --- | -------- | ------------ |
| 빨강  | VCC      | **3V3**      |
| 검정  | GND      | **GND**      |
| 흰색  | SDA      | **D4 / SDA** |
| 노랑  | SCL      | **D5 / SCL** |

XIAO 공식 핀맵도 D4를 SDA, D5를 SCL로 정의한다. ([Seeed Studio Wiki][4])

따라서 초기 하드웨어는:

```text
Pre-Soldered XIAO
       │
       │ Female Jumper 4가닥
       │
Grove Conversion Cable
       │
       │ Grove Connector
       ▼
Grove 5-Way Switch
```

가 되며, **납땜 없이 스틱 입력 개발이 가능하다.**

# 7. 개발용과 최종용 스틱의 차이

Grove 5-Way Switch는 최종 제품에 넣지 않는다.

크기가 40×20mm라 반지에는 너무 크기 때문이다.

최종 반지에서는:

**Alps Alpine SKRH 계열**

을 사용한다.

SKRH는 공식적으로 **4-direction + Center-push Surface Mount switch**이며, 모델에 따라 약 **7.35~7.5mm 크기, 두께 약 1.8mm**에 불과하다. ([Alps Alpine][7])

구조는:

```text
         SKRH
          ↓
     소형 Custom PCB
          ↓
       6가닥 배선
          ↓
         XIAO
```

가 된다.

SKRH는 Grove와 달리 I²C 모듈이 아니다.

단순 기계식 접점이므로 XIAO GPIO에 직접 연결한다.

```text
UP      → GPIO
DOWN    → GPIO
LEFT    → GPIO
RIGHT   → GPIO
CENTER  → GPIO
COMMON  → GND
```

즉 **신호 5개 + 공통 GND = 총 6가닥**이다.

SKRH 전용 PCB에는 복잡한 회로가 필요 없으므로 **대략 10×10mm급 PCB**로 만드는 것을 목표로 한다.

# 8. 반지 최종 물리 구조

오른손 검지 착용 기준이다.

```text
                   손등

             ┌────────────┐
             │    XIAO    │── USB-C
             └────────────┘


엄지 쪽                              중지 쪽

[전원 스위치]                       비움
[SKRH 스틱]


             ╭──────────╮
            │    검지    │
             ╰────┬─────╯
                  │
             [50mAh Battery]

                  손바닥
```

### 위쪽

**XIAO nRF52840 Sense**

상부에 배치한다.

USB-C 포트가 외부에서 접근 가능하도록 케이스에 충전구를 만든다.

### 왼쪽 — 엄지 방향

**위: 전원 스위치**
**아래: SKRH 4방향 + 중앙 클릭 스틱**

엄지가 자연스럽게 접근할 수 있도록 조작부를 한쪽에 집중한다.

### 오른쪽 — 중지 방향

**아무 부품도 배치하지 않는다.**

검지와 중지 사이 공간이 좁기 때문이다.

### 아래 — 손바닥 방향

배터리를 넣는다.

상부에 XIAO와 적층하지 않는 이유는:

* 상부 두께 감소
* 무게 중심 개선
* 반지 회전 완화
* XIAO BLE 안테나와 배터리의 금속 구조 겹침 감소

이다.

# 9. 최종 배터리

현재 후보는:

**Grepow GRP1240R1**

로 확정한다.

공식 사양:

| 항목     |               값 |
| ------ | --------------: |
| 전압     |            3.7V |
| 완충전압   |            4.2V |
| 용량     |       **50mAh** |
| C-rate |          **1C** |
| 직경     |        **12mm** |
| 두께     |       **4.1mm** |
| 무게     | **1.4 ± 0.15g** |

([Grepow][8])

이 배터리를 선택한 이유는 **50mAh 용량을 유지하면서 footprint가 Ø12mm로 매우 작기 때문**이다.

---

# 10. 충전 구조

배터리 자체에는 USB-C가 없다.

XIAO의 USB-C와 내장 충전회로를 이용한다.

```text
USB-C
  ↓
XIAO
  ↓
내장 충전회로
  ↓
GRP1240R1
```

XIAO nRF52840 Sense는 배터리 충전전류를 **50mA 또는 100mA**로 선택할 수 있다. ([Seeed Studio Wiki][4])

GRP1240R1이 50mAh / 1C이므로 현재 설계에서는 **50mA 충전 모드**를 사용한다.

100mA 충전은 사용하지 않는다.

---

# 11. 전원 스위치

최종 반지의 스위치는 제스처 모드 스위치가 아니라 **전체 전원 ON/OFF 스위치**다.

사용하지 않을 때:

```text
Battery
  X
Power Switch OFF
  X
XIAO / IMU / BLE
```

즉 전체 시스템을 끈다.

사용할 때 스위치를 ON하면:

1. XIAO 부팅
2. BLE advertising
3. 기존 스마트폰과 재연결
4. 스틱 및 제스처 사용

순서로 동작한다.

한 번 최초 페어링한 이후에는 본딩 정보를 저장해두고, 이후에는 전원 ON 시 자동 재연결하도록 설계한다.

완전 전원 OFF 방식이므로 **켜는 순간 0초 반응은 아니며 BLE 재연결에 짧은 시간이 필요**하다. 실제 Android 스마트폰에서 재연결 체감시간을 초기 PoC에서 측정한다.

---

# 12. 배터리 수명 방향

이 장치는:

> 침대에서 사용 → 끝나면 전원 OFF

를 전제로 한다.

따라서 상용 스마트링처럼 24시간씩 동작할 필요가 없다.

50mAh로도 **한 번의 사용 세션에는 충분한 수준**을 목표로 하며, 정확한 연속 사용시간은 실제 펌웨어 이후 측정한다.

최종 설계 판단에서:

**배터리 지속시간보다 크기와 착용감을 우선**

한다.

# 13. Embedded AI 구조

AI 추론은 스마트폰이 아니라 반지에서 수행한다.

```text
IMU raw data
     ↓
nRF52840
     ↓
TinyML
     ↓
Gesture Class
     ↓
BLE에는 결과만 전송
```

스마트폰에서 AI를 돌리는 방식도 가능하지만 최종 구조에서는 다음 이유로 온디바이스 추론을 유지한다.

* 센서 데이터를 외부로 계속 전송하지 않아도 됨
* 제스처 판단과 센싱을 하나의 임베디드 시스템으로 통합
* 스마트폰 앱이 AI 모델을 알 필요 없음
* TinyML 자체가 프로젝트 핵심 기술 요소
* 통신량 감소

다만 **TinyML이 무조건 BLE 원시 데이터 전송보다 저전력이라는 가정은 하지 않는다.**

향후 동일 조건에서:

```text
A. IMU → BLE Raw → 스마트폰 AI

B. IMU → TinyML → 명령만 BLE
```

의 소비전력을 실측 비교할 수 있다.

# 14. AI 데이터

XIAO 내장 LSM6DS3TR-C는 6축 IMU이므로 다음 데이터를 수집한다. ([Seeed Studio Wiki][4])

```text
timestamp
acc_x
acc_y
acc_z
gyro_x
gyro_y
gyro_z
label
```

초기 클래스:

```text
UP
DOWN
LEFT
RIGHT
IDLE / OTHER
```

을 고려한다.

사용자의 실제 검지 움직임을 여러 속도·크기·각도에서 반복 수집하여 학습 데이터를 만든다.

AI 모델은 nRF52840에서 실행 가능한 작은 1D CNN 또는 소형 신경망부터 검토한다.

# 15. Android 앱

Android companion app은 주로 **AI 제스처 명령 처리**를 담당한다.

주요 기능:

| 기능        | 구현                        |
| --------- | ------------------------- |
| 스틱 포인터    | BLE HID Mouse             |
| 중앙 클릭     | BLE HID Mouse             |
| AI 제스처 수신 | Custom BLE GATT           |
| 실제 스와이프   | AccessibilityService      |
| 초기 설정     | BLE 연결 및 Accessibility 권한 |

`dispatchGesture()`를 이용하면 제스처를 터치스크린에 직접 수행된 것처럼 전달할 수 있어 다른 일반 앱 화면에서도 스와이프를 발생시키는 구조가 가능하다. ([Android Developers][3])

# 16. 가장 먼저 검증할 기술 리스크

현재 가장 중요한 것은 AI가 아니다.

**BLE HID Mouse와 Custom GATT가 하나의 XIAO에서 Android와 동시에 안정적으로 동작하는지**를 가장 먼저 검증한다.

목표 PoC:

```text
XIAO
 ├─ HID Mouse
 │    ↓
 │ Android Pointer 이동
 │
 └─ Custom GATT
      ↓
   Android App에 임의 데이터 전송
```

그리고 동시에:

* 마우스 이동
* Custom notification 수신
* 전원 재연결
* Bluetooth OFF/ON 후 복구
* 앱 종료 후 재실행

을 테스트한다.

Arduino/Bluefruit 환경에서 안정적으로 구현되지 않는다면 **nRF Connect SDK / Zephyr로 펌웨어 환경 변경**을 검토한다.

# 17. 개발 단계

### Phase 1 — 통신 PoC

사용 부품:

**이미 주문한 Pre-Soldered XIAO만 사용**

USB-C로 PC에 연결한다.

목표:

* 펌웨어 업로드
* BLE 연결
* BLE HID Mouse 동작
* Custom GATT 동시 동작 확인

---

### Phase 2 — 개발용 방향 입력

추가:

* Grove 5-Way Switch
* 110990028 Grove-Female Jumper 케이블

납땜 없이 연결한다.

목표:

* ↑↓←→ 입력 읽기
* 중앙 클릭
* Android 포인터 이동
* 실제 YouTube/웹툰에서 조작 테스트

---

### Phase 3 — IMU

XIAO 내장 IMU를 사용한다.

목표:

* 6축 Raw 데이터 읽기
* PC로 로그 저장
* 실제 손가락 동작 데이터 수집

---

### Phase 4 — AI

PC에서 모델을 학습하고 XIAO로 배포한다.

목표:

* LEFT / RIGHT / UP / DOWN 분류
* 실시간 TinyML 추론
* 오인식률 측정

---

### Phase 5 — Android 제스처 제어

목표:

* Custom BLE 명령 수신
* AccessibilityService 구현
* YouTube / 웹툰 등에서 실제 스와이프

---

### Phase 6 — 무선 전원

추가:

* GRP1240R1 50mAh
* 전체 전원 스위치

목표:

* 배터리 구동
* USB-C 충전
* 실제 소비전력 측정
* 전원 ON 후 자동 BLE 재연결 시간 측정

---

### Phase 7 — 착용 프로토타입

개발용 Grove를 제거하고:

* SKRH
* 약 10mm급 소형 PCB
* 얇은 6가닥 배선
* 3D 프린팅 케이스

로 교체한다.

Pre-Soldered XIAO의 긴 핀헤더는 반지에 불리하므로 **착용형 단계에서는 헤더 제거 또는 별도의 Unsoldered XIAO 사용**을 검토한다.

# 18. 기구적 설계 주의사항

### 반지 회전

엄지가 측면 스틱을 밀면 반지 전체에 회전 토크가 생긴다.

대응:

* 밴드 폭 증가
* 내부를 완전 원형이 아니라 일부 평평하게 제작
* 배터리를 아래에 배치해 무게 중심 분산
* 스틱 위치를 검지에 최대한 가깝게 배치

### 배터리 하부 돌출

배터리는 Ø12 × 4.1mm이므로 케이스까지 포함하면 아래쪽이 더 두꺼워진다.

다만 침대용이라는 한정된 사용 목적상 어느 정도 허용할 수 있다.

배터리는 외부 압력을 직접 받지 않도록 **단단한 케이스 내부에 보호**한다.

### 배선

최종 SKRH ↔ XIAO는 6가닥, 하부 배터리 ↔ XIAO는 전원 배선이 필요하다.

배선은 반지 본체 내부에 고정하여 손가락을 굽힐 때 반복적으로 접히지 않도록 한다.

납땜 직후에는 **strain relief**를 두어 배선에 가해지는 힘이 XIAO 패드나 SKRH PCB 납땜부에 직접 전달되지 않게 한다.

### 안테나

XIAO에는 온보드 BLE 안테나가 이미 존재한다. ([Seeed Studio Wiki][4])

안테나 주변에는 가능한 한:

* 배터리
* 금속 스위치
* 금속 케이스
* 스틱 PCB

를 가까이 두지 않는다.

배터리를 하부로 이동시킨 현재 구조가 상부 적층보다 유리하다.

목표 거리는 침대에서 스마트폰 거치대까지이므로 약 1m 전후의 짧은 통신을 기준으로 실제 착용 테스트한다.

# 19. 개발용과 최종 구조 비교

|       | 초기 개발             | 최종 반지                 |
| ----- | ----------------- | --------------------- |
| MCU   | Pre-Soldered XIAO | XIAO 또는 향후 Custom PCB |
| 방향 입력 | Grove 5-Way       | SKRH                  |
| 연결    | I²C 4선            | GPIO 6선               |
| 납땜    | 거의 없음             | 필요                    |
| 전원    | USB-C             | 50mAh 배터리             |
| 스위치   | 없음                | 전체 전원 스위치             |
| 케이스   | 없음                | 3D 프린팅                |
| 목적    | 기능 검증             | 실제 착용 검증              |

이 구분이 꽤 중요해.

**Grove는 최종 제품 부품이 아니라 개발을 쉽게 해주는 임시 입력장치**다.

# 20. 성공 기준

프로젝트 1차 완성 기준은 다음이다.

1. Android와 자동 재연결 가능
2. 엄지 스틱으로 포인터 상하좌우 이동 가능
3. 중앙 클릭 가능
4. HID와 Custom BLE가 동시에 안정적으로 작동
5. 최소 4개의 제스처를 XIAO 내부 AI가 실시간 분류
6. 제스처로 실제 YouTube/웹툰 화면 조작 가능
7. 50mAh 배터리로 한 번의 사용 세션을 충분히 감당
8. USB-C 충전 가능
9. 실제 오른손 검지에 착용 가능
10. 조이스틱 사용 시 반지가 과도하게 회전하지 않음
