# Causal Window 길이 1차 비교

2026-09-28에 Edge Impulse 프로젝트 `RingPilot`(ID `1122630`)의 방향별 3초 원시 샘플과 `data/annotations/gesture-completions.csv`를 이용해 `800 / 1200 / 1600 ms` 입력 길이를 비교했다.

이 실험의 목적은 최종 정확도를 주장하는 것이 아니라, 명백히 짧은 입력 길이를 제거하고 실제 causal CNN/TCN에서 비교할 후보를 줄이는 것이다.

## 방법

- 입력: 100 Hz, accel+gyro 6축
- 목표: 자연 복귀 완료 후 150 ms만 `UP / DOWN / LEFT / RIGHT`, 나머지는 `NONE`
- 추론 간격: 50 ms
- 데이터: 자동 주석을 통과한 `AUTO` 30개
- 분할: 방향 비율을 유지한 5-fold 교차검증, 동일 3초 원본에서 나온 window는 같은 fold에만 배치
- 별도 확인: `REVIEW` 10개는 학습과 교차검증에서 제외하고 stress set으로만 사용
- 진단 모델: 10개 시간 bin에서 6축 평균·표준편차와 양 끝 차이를 계산한 126개 특징 + 선형 softmax
- 이벤트 후처리: 같은 방향 2회 연속 검출 시 1회 발생, `NONE` 2회 연속 후 재무장

재현 명령:

```powershell
node tools/compare-window-lengths.js --project-id 1122630 --lengths 800,1200,1600 --folds 5 --epochs 80
```

명령은 원격 샘플을 읽기만 하며 Edge Impulse의 데이터와 라벨을 수정하지 않는다.

## 결과

| 입력 길이 | 원시 입력 버퍼 | 주동작 시작까지 포함한 샘플 | 이벤트 검출 | 목표 밖 이벤트 | 목표 밖 이벤트/3초 clip | NONE window 오검출 | 방향 macro F1 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 800 ms | 1,920 B | 6/30 (20.0%) | 6/30 (20.0%) | 51 | 1.700 | 21.83% | 0.2163 |
| 1,200 ms | 2,880 B | 19/30 (63.3%) | 12/30 (40.0%) | 40 | 1.333 | 22.25% | 0.2532 |
| 1,600 ms | 3,840 B | 28/30 (93.3%) | 8/30 (26.7%) | 38 | 1.267 | 19.97% | 0.2718 |

교차검증 fold별 검출 지연 중앙값들의 중앙값은 각각 `90 / 40 / 70 ms`였다. 방향 양성 window recall은 `41.11 / 43.33 / 43.04%`로 비슷했다. 방향별 F1에서 `RIGHT`는 각각 `0.0735 / 0.0556 / 0.0714`로 세 조건 모두 특히 낮았다.

`REVIEW` 10개 stress set은 800/1200/1600 ms에서 각각 4/2/0개만 이벤트를 맞혔고 목표 밖 이벤트도 18/14/9개였다. 자동 주석의 어려운 사례를 현재 모델이 처리한다고 볼 수 없다.

## 판단

1. `800 ms`는 30개 중 24개에서 양성 window가 주동작 시작을 잃는다. 이벤트 검출과 오검출도 개선되지 않았으므로 주 후보에서 제외한다.
2. `1200 ms`는 이 진단 모델에서 이벤트 recall과 지연이 가장 좋다. 그러나 필요한 시작 맥락을 모두 담은 샘플이 63.3%뿐이고 `RIGHT` 구분도 나쁘다.
3. `1600 ms`는 93.3%에서 시작 맥락을 보존하고 macro F1과 NONE 오검출이 가장 낫다. 이벤트 recall이 1200 ms보다 낮으므로 길기만 하면 좋아진다고 결론낼 수는 없다.
4. 다음 causal CNN/TCN의 기본 후보는 `1600 ms`, 비교군은 `1200 ms`로 둔다. 1600 ms 원시 버퍼는 1200 ms보다 960 B 크므로 입력 버퍼 자체는 큰 부담이 아니지만, 실제 tensor arena·연산시간·전력은 모델 빌드 후 측정한다.
5. 셋 중 어느 것도 현재 성능으로 사용할 수 없다. 최고 이벤트 recall이 40%이고 모든 조건에서 3초 clip당 목표 밖 이벤트가 1회를 넘는다.

## 해석 제한

- 선형 특징 모델은 길이 후보를 거르는 진단 기준선이며 최종 causal CNN/TCN이 아니다.
- 한 사용자·한 수집 세션의 30개 샘플이므로 사용자/날짜/착용 변화 일반화 결과가 아니다.
- `completion_ms`는 자동 계산 후보이며 사람이 파형을 보며 확정한 정답이 아니다.
- 3초 clip의 목표 밖 이벤트는 연속 착용 상태의 `false positive/hour`와 같지 않다.
- 이 자료에는 빠른 연속 제스처가 없어 최소 반복 간격과 실제 중복 이벤트율을 평가할 수 없다.
