# BLE PoC 테스트

대상: Seeed XIAO nRF52840 Sense, Seeed nRF52 Boards(non-mbed) 1.1.13.
휴대폰: Galaxy S10 / Android 12 (사용자 확인).

## 1. 마우스 검증
1. Arduino IDE에서 `firmware/ble_poc/ble_poc.ino`를 열고 기존 Sense 보드/포트로 업로드한다.
2. 시리얼 모니터를 115200 baud로 열고 `?`를 전송하면 상태를 확인할 수 있다. 줄바꿈 설정은 어느 것이든 가능하다.
3. 휴대폰 설정 → 연결 → Bluetooth에서 `SmartRing-PoC`를 선택하여 페어링한다.
4. 시리얼 모니터에서 `w`, `a`, `s`, `d`를 전송하면 위/왼쪽/아래/오른쪽으로 한 번 이동한다. `dddd`처럼 반복 입력도 가능하다.
5. `c`는 왼쪽 클릭 후 자동 해제한다. 홈 화면의 무해한 위치에서 먼저 확인한다.
6. `HID queued`는 송신 API 성공이며 휴대폰 동작을 보증하지 않는다. 실제 포인터 이동과 클릭을 따로 확인한다.

## 2. Custom GATT 동시 검증
휴대폰의 BLE GATT 검사 앱으로 이미 페어링한 같은 기기에 연결하고 서비스를 검색한다.
HID와 GATT는 같은 휴대폰의 한 물리 BLE 연결을 공유하는 구성이며, 두 번째 휴대폰을 연결하는 시험이 아니다.

- Service UUID: `b27a1000-8c5e-4b62-9a21-33dd714e9001`
- Characteristic UUID: `b27a1001-8c5e-4b62-9a21-33dd714e9001`
- 속성: READ, NOTIFY. 알림을 구독하면 1초마다 ASCII `seq=숫자` 수신.
- 광고에는 HID만 포함. Custom 서비스는 연결 후 서비스 검색으로 찾는다.
- 앱에 따라 연결 중인 기기는 스캔 목록 대신 본딩된 기기 목록에서 선택해야 할 수 있다.
- 숫자 수신 중 시리얼 명령으로 포인터를 움직여 둘 다 작동하는지 확인한다.
- 숫자는 부팅 후 초당 증가하며 전원 재시작 시 초기화된다. 알림 재구독 전의 누락은 전송 실패로 집계하지 않는다.
- 자체 Android 앱과 접근성 스와이프는 이번 코드에 포함되지 않는다.

## 3. 복구 검증 및 결과 기록
보드 USB 재연결, 휴대폰 Bluetooth OFF/ON, GATT 앱 종료/재실행을 각각 시험한다.
각 조건에서 HID 복구와 GATT 재연결/알림 재구독을 따로 확인한다.
연결 상태 출력만으로 자동 재연결 성공이라고 판정하지 않는다.
