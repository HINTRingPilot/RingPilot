# 영상 관찰 갈래 준비 — 미실행

이번 NONE 비교와 별도인 개발용 관찰이다. 영상 관찰을 했다고 기록하거나 동기화 오차를 보장하지 않는다.

1. 사용자가 손가락·손·필요한 팔의 복귀를 볼 수 있는 촬영 기기와 고정 방법을 준비한다. 실제 FPS·영상 보관 위치를 기록한다. 60 fps는 계획상 권장 조건이며 준비됐다고 가정하지 않는다. 영상은 Git에 넣지 않는다.
2. 앱의 CSV 0 ms는 첫 보드 슬롯, 비프는 앱 안내 시각이다. 클립별 첫 슬롯 번호를 별도 기록하는 앱 변경과 검증이 필요하다. 이 작업은 이번 실험에서 구현하지 않는다.
3. 두드림 같은 물리 표식 또는 보드 시계에 연결된 LED 표식의 영상-센서 대응을 확인한다. 두드림은 진동 전달·프레임 판독 오차가 있고 첫 슬롯 기록만으로 정확한 동기화가 완성되지 않는다. 표식은 분석할 4초 구간 밖에서 관찰하거나, 별도 표식 기록과 클립의 시각 관계를 남겨 에너지 기반 주석을 오염시키지 않는다.
4. 먼저 파일럿 3개에서 시작/끝 대응·드리프트·반복 오차를 실제로 측정한다. 기존 문서의 ±26 ms는 모델 추정이지 측정값이 아니다. ±50 ms는 작업 목표이며 통과했다고 가정하지 않는다. 불확실성을 측정할 수 없으면 완료 시각 비교를 진행하지 않는다.
5. 파일럿을 통과하면 우선 5자세×4방향 20개를 개발용으로 촬영한다. 모델 발행·자동 e를 가린 상태에서 사람이 복귀 완료의 가능한 구간을 먼저 표시한다. 자동 e는 그 뒤에 공개한다.
6. 이 자료는 주석 타당성 확인에 쓰는 개발 자료다. 개선판의 독립 최종 평가 자료와 구분한다. 모든 항목은 장비·앱 변경·파일럿에 대한 실제 준비가 된 뒤 실행한다.
