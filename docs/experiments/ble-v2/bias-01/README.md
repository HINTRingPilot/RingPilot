# bias-01 — 학습 영점과 실사용 온라인 영점 비교(2026-11-16)

질문: 학습은 클립 0~890 ms(가만히 있으라고 안내한 신호 전 구간)로 자이로 영점을 잡고, 보드는 "마지막으로 0.5초 정지한 구간"(`still_estimates`, 축별 표준편차 3 dps 미만)으로 잡는다. 이 차이가 실사용 입력을 학습 때와 다르게 만들어 발행에 영향을 주는가?

실행: `ml/.venv/Scripts/python.exe docs/experiments/ble-v2/bias-01/bias_check.py` → `bias-01.json`, `bias_timeline.png`.

## A. 학습 기준

방향 클립 294개(5개 세션)의 신호 전 영점(dps): 중앙값 X 1.61, Y −4.36, Z −0.66. 1~99% 범위 X −4.8~6.7, Y −14.0~0.1, Z −4.2~9.2. 학습 데이터 자체의 영점도 클립마다 꽤 흩어져 있다(특히 Y).

## B. 실사용 온라인 영점

| | field-01(130초) | field-02(66초) |
|---|---|---|
| 온라인 영점 중앙값 | 1.61, −5.28, −0.91 | 1.40, −4.06, −0.98 |
| 학습 1~99% 범위 밖에 있던 시간 | 1.5% | 0% |
| 학습 중앙값과 5 dps 넘게 다른 시간 | 6.1% | 34.4% |
| 3 dps 넘게 튄 횟수 | 9 | 3 |

- 온라인 영점은 대부분 학습 클립이 겪은 범위 안에 있다.
- 범위를 벗어난 것은 field-01의 93.9~94.6초 한 번(Y −20.4 dps, 0.7초)뿐이다. 느린 움직임이 정지로 판정된 것으로 보인다.
- field-02는 15~38초 동안 정지 구간이 없어 Y −9.6 dps를 23초 동안 그대로 썼다(오래된 영점). 그래도 학습 범위 안이다.

## C. 영점만 바꿔 재생(보드 규칙: 발행 150 ms 뒤 지우기 + quiet)

| 기록 | 영점 | 정상 | 무발행 | 다른 방향 포함 |
|---|---|---|---|---|
| field-01(후보 72) | 온라인(지금 보드) | 61 | 10 | 1 |
| | 학습 중앙값으로 고정 | 61 | 9 | 2 |
| field-02(후보 48) | 온라인(지금 보드) | **46** | 2 | 0 |
| | 학습 중앙값으로 고정 | 40 | 8 | 0 |

고정 영점이 더 낫지 않다. field-02에서는 온라인 영점이 정상 6개를 더 살렸다. 실제 영점이 학습 중앙값에서 5 dps쯤 떨어져 있었고, 온라인 추정이 그걸 따라갔기 때문으로 본다.

## 결론

"학습 영점과 실사용 영점이 달라 입력이 어긋난다"는 우려는 이 기록에서 확인되지 않았다. 온라인 영점은 학습 데이터가 이미 겪은 범위 안에서 움직이고, 고정 영점보다 같거나 낫다. 남은 위험은 느린 움직임이 정지로 잡혀 영점이 잠깐 튀는 경우(130초 중 0.7초 한 번)다. 지금은 손대지 않는다. 고친다면 "학습 범위를 크게 벗어나는 갱신은 받지 않기" 정도가 후보다.
