# 작업 D — 다음 실험 요인 제안 (2026-10-25)

> **제안이며 결정이 아니다.** 요인 선택은 사용자 결정이고, 선택 전에 정답 시각·문턱·가중치·선택 점수를 바꾸지 않는다. 작업 C의 영상 관찰(촬영, 사람 주석)은 **실행하지 않았다**(촬영 기기와 사람이 필요하고 현재 시스템은 센서–영상 시각 대응을 50 ms 안으로 보장하지 못한다: [sync-feasibility.md](sync-feasibility.md)). 따라서 아래 판단은 작업 A, B와 C의 코드 조사만 근거로 한다. 계획: [2026-10-25-v2-completion-validation.md](../../../../superpowers/plans/2026-10-25-v2-completion-validation.md) 6절.

## 1. 확인한 사실

모두 기존 자료(5세션 336개 원본)와 저장된 예측·발행 로그를 읽은 값이다. 새 학습은 없다. 같은 클립을 여러 seed·fold가 반복해 보므로 건수를 독립 표본 수로 읽지 않는다.

| 출처 | 사실 | 확정 정도 |
|---|---|---|
| 표본 보고서([samples](samples/summary.md)) | 표본 26개(기본 20 + 간격 큰 5 + 끝부분 잘림 1) × 5 seed = 130쌍에서 발행 재현이 저장된 로그와 정확히 일치(130/130)하고, 모든 표본이 그 fold의 학습에 쓰이지 않았다(130/130). 130쌍 중 85쌍이 발행했고(총 111건), 조기 발행이 있는 쌍 44, 정검출이 있는 쌍 43이다. 5 seed 모두 발행하지 않은 표본은 1개뿐이다 | 계산으로 확인(독립 재현함). 표본의 비율은 전체 대표값이 아니다 |
| 간격 대 조기 발행([gap-vs-early](gap-vs-early/gap-vs-early.md)) | e와 주동작 종료의 간격이 클수록 조기 발행이 많고 정검출이 적다. S-P5 E=60에서 간격 0~100 ms 클립은 조기 7.6%·정검출 55.3%, 300 ms 이상은 조기 55.3%·정검출 10.6%이다. 같은 구간에서 발행하는 비율은 67.6%와 66.3%로 거의 같다. 순위 상관은 분할×E 13개 조합 전부에서 조기 +0.31~+0.60, 정검출 −0.08~−0.63이다 | 계산으로 확인. **관찰된 관계이며 원인이 아니다** |
| NONE 선택([none-selection](none-selection/none-selection.md)) | 25개 fold의 학습 창 선택이 config와 정확히 일치한다. 복귀 말미 `[−300,0) ms` 창은 클립마다 6개 있고, 선택된 in_progress NONE 중 말미 300 ms의 비율(S-P5 39.9%)이 가능한 비율(34.2%)보다 낮지 않다. 그러나 절대량이 작아 (클립×fold) 관측의 70~72%(S-P5 498/711, C 676/944)에서 말미 300 ms 선택이 0개다. 클립당 in_progress 선택은 최대 1개다 | 계산으로 확인(독립 재현함) |
| 세션 편중(같은 자료) | in_progress NONE 선택이 경로 순서에 따라 세션에 치우친다. 분할 C의 학습에서 P5 방향 클립은 in_progress 3,528개와 완료 후 5,120개 중 **0개**가 선택됐고(P4 3.6%, P1 6.7%), S-P5 보정에서도 P4 1.3%, P1 6.9%다 | 계산으로 확인(독립 재현함). 선택 코드의 동작(v1부터)이며 결과에 미친 영향은 측정하지 않았다 |
| 동기화 조사([sync-feasibility](sync-feasibility.md)) | 현재 앱·펌웨어만으로는 CSV 0 ms와 영상 시각을 연결할 수 없다(시작 비프와 첫 수신 슬롯이 일치하지 않고 패킷이 약 100 ms 묶음이다). 앱이 각 클립의 첫 슬롯 번호를 저장하고, 클립 밖에서 두드림 표식을 기록하며, 60 fps 이상으로 촬영하면 가능하다(추정 오차 ±26 ms, 모델 추정) | 코드로 확인. 실제 BLE 지연·시계 드리프트는 측정 전 |

## 2. 사실이 아닌 것

- 조기 발행이 **완료 주석의 오류** 때문이라는 증거는 없다. 간격과의 관계는 모델이 주동작 종료 무렵에 반응하는 경향과 일치하지만, 간격이 큰 클립이 다른 점(느린 복귀, 떨림 등)에서도 다를 수 있다.
- e와 `main_motion_end_ms`는 같은 자동 도구의 값이라 둘 중 무엇이 "자연 복귀 완료"에 맞는지는 이 자료로 가를 수 없다. 사용자 의도는 "자연스러운 복귀 뒤"이므로 주동작 종료 직후의 발행이 의도에 맞을 가능성도 배제하지 못한다.
- 복귀 말미 NONE이 조기 발행을 일으킨다는 증거도, 아니라는 증거도 없다. 말미 구간이 다른 in_progress 구간보다 덜 뽑히지는 않았다는 것까지만 안다.
- 후처리가 어떻게 영향을 주는지는 이번에 조사하지 않았다.

## 3. 계획 6절의 표와의 대응

| 계획의 행 | 조건 | 현재 상태 |
|---|---|---|
| 완료 후보 정의 비교 | 사람이 본 완료 구간과 e의 체계적 어긋남이 관찰됨 | **판정 불가** — 영상 관찰이 없다 |
| NONE 말미 구성 비교 | e가 관찰과 대체로 맞고 말미 NONE이 적게 선택됨 | **조건 불성립** — e의 타당성 미확인, 말미 NONE이 상대적으로 덜 뽑히지도 않음 |
| 후처리 replay 비교 | e를 바꿀 근거가 없고 발행 시점 조사가 필요함 | 근거 없음 |
| 관찰 방법 보완 또는 원인 미확정 | 영상·동기화가 불충분하거나 근거가 충돌함 | **해당** — 이 행의 원칙은 "점수를 좋게 하려고 e 이동·허용 구간 확대·가중치 변경을 하지 않는다"이다 |

## 4. 제안

두 갈래이며 서로 다른 요인이라 한 실험에서 섞지 않는다.

### 제안 1 (영상 없이 지금 가능): NONE 선택을 세션·클립에 걸쳐 고르게 하는 단일 요인 비교

- **바꾸는 것:** `choose_training`이 같은 종류 안에서 파일을 경로 순서로 돌며 할당량을 채우는 방식 대신, 같은 총 NONE 수를 세션·클립에 층화해 고르게 뽑는다. **총 NONE 창 수, NONE 종류 비율, e, 양성 폭 150 ms, 모델, 입력, 후처리, 선택 점수, 학습 설정, seed·fold는 그대로 둔다.**
- **이유:** 측정된 결함(경로 순서에 따른 세션 편중, 분할 C에서 P5 방향 클립 NONE 0개)이고 e와 무관하다. 영상이 없어도 수정·검증할 수 있고, 같은 seed·fold 대응 비교가 된다.
- **기대하지 말 것:** 이것이 조기 발행을 줄인다는 근거는 없다. "효과 없음"도 결과로 기록한다. 판정 기준(예: 같은 seed끼리 선택 점수·정검출률·조기 발행 비율의 상승/하락 개수)을 실행 전에 새 protocol로 고정한다.
- **반대 근거:** 조기 발행의 주된 원인이 완료 시각 정의라면 효과가 작을 수 있다. 그래도 이후 완료 시각 비교 결과를 해석하려면 NONE 편중이 먼저 정리돼 있어야 두 효과가 섞이지 않는다.
- **자료 사용:** 기존 336개 원본은 개발에 쓸 수 있으나 이미 관찰됐으므로 독립 평가 결과가 아니다. 새 protocol, 새 `--run-id`로 실행하고 과거 해시는 덮어쓰지 않는다. 새 protocol을 만드는 명령은 이때 일반화한다.

### 제안 2 (사용자 수행 필요): 완료 시각의 타당성은 영상 관찰로 확인

- 간격과 조기 발행의 관계가 일관되게 강하므로 완료 시각 정의는 계속 가장 중요한 후보다. 그러나 어느 시각이 맞는지는 독립 관찰 없이 판단할 수 없다. 센서 기반 대안 정의끼리 비교하는 것은 같은 도구의 값을 비교할 뿐이라 계획이 금지한 "독립 근거 없는 e 이동"에 해당한다.
- 사용자가 할 일은 [sync-feasibility.md](sync-feasibility.md) 8절에 있다(카메라 60 fps 이상과 삼각대, 두드림 표식 촬영 절차, 영상 보관 위치 결정). 코드로 구현할 일은 앱이 클립마다 첫 슬롯 번호를 저장하는 것(`MainActivity`)이며 이 단계에서는 구현하지 않았다.
- 파일럿 3개로 시각 오차 ±50 ms 이내를 확인한 뒤에만 본 관찰 20개로 확대한다. 관찰 결과에 따라 이 표의 첫 행(완료 후보 정의 비교) 또는 네 번째 행이 확정된다.

## 5. 이 단계의 한계

- 영상 관찰·사람 주석이 없어 e의 타당성은 결론이 없다.
- 표본 26개는 이상 사례 점검용이며 성능·대표성의 근거가 아니다.
- 모든 숫자는 5 seed × 여러 fold가 같은 클립을 반복해 본 값이고 독립 표본이 아니다.
- 한 사용자, 같은 날의 5개 자세 세션이다.
- 개선판의 독립 평가에는 설계를 고정한 뒤 새로 수집한 자료가 필요하다(이 336개와 향후 관찰 자료는 모두 개발용).
