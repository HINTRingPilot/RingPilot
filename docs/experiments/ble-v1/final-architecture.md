# BLE v1 최종 아키텍처 결정 기록

작성: 2026-10-21 / 상태: 미선정

현재 [ModelArchitecture.md](../../ModelArchitecture.md)는 출발 기준선이다. 실험 8이 끝났다는 이유만으로 최종 채택하지 않고, 실제 평가와 보드 제약을 만족한 범위로 결정한다.

2026-10-21 [실험 2](실험2_진행기록.md)에서 훈련 loss의 클래스 균형 가중치를 비교했으나 미매칭 발행이 늘어 해당 변경을 채택하지 않았다. 기준 CNN·라벨·입력·후처리 사양은 유지하며, 이것이 현재 모델의 사용 가능성을 입증한 것은 아니다.

같은 날 [실험 3](실험3_진행기록.md)에서 사용자 목표를 자연 복귀 후 발행으로 확인했다. 연속 자료를 수집할 수 없어 기존 clip에서 완료 후 훈련 라벨150/300 ms 사전 비교를 했고, 300 ms에서 조기 발행이 늘어 변경을 채택하지 않았다. 정식 연속 검증과 최종 라벨 선정은 미완료다.

[실험 4](실험4_진행기록.md)의1200/1600 ms 비교에서는1200 ms의 설계 MAC가25% 줄었으나 공통 시각·준비 시점 재생에서 발행 오류가 늘어 변경을 채택하지 않았다.1600 ms 기준을 유지하며 길이의 최적성·보드 속도는 검증하지 않았다.

[실험 5](실험5_진행기록.md)의 Flatten/GAP 비교에서는 GAP가 파라미터를9,493→3,253으로 줄였지만 세 seed 모두 방향 명령0/8로 누락해 변경을 채택하지 않았다. Flatten을 비교 기준으로 유지한다. 읽기 방식과 용량이 같이 바뀐 조건의 결과이며 GAP 일반의 부적합을 입증한 것은 아니다.
