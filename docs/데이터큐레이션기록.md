# 데이터 큐레이션 기록 (Data Curation Log)

데이터셋을 목적에 맞게 다듬은 결정을 한곳에 모은다. 무엇을, 왜 뺐는지만 짧게 적는다. 자세한 경과는 [진행기록](진행기록.md)의 해당 날짜에 있다.

원칙
- 원본은 지우지 않는다. 데이터에서 빼는 클립은 각 세션의 `excluded/` 폴더로 옮기고, 사유는 `excluded/EXCLUDED.txt`와 `data/annotations/ble-v2/records.json`(`excluded_by_user`: 경로·sha256·사유, `revisions`: 날짜·뺀 경로)에 남긴다.
- 데이터에 남기되 따로 지켜볼 클립(약한 동작)은 `data/annotations/ble-v2/weak-gestures.json`에 둔다. 학습·평가에 모두 쓰고, 요약에서 검출률을 따로 보고한다.
- 분할은 다시 뽑지 않는다. 고정 분할(`data/splits/v2-*.json`)에서 뺀 경로만 지우고 `revisions`에 기록한다.
- 기준을 먼저 정하고 그 기준에 맞는 클립을 모두 뺀다. 모델 결과를 본 뒤에 정한 기준은 그렇다고 밝힌다.

### 3. 약한 동작 — 14개, 빼지 않고 따로 보고 (2026-10-28, 모델 무발행 진단 뒤)

최종 결정: **약한 동작도 조작으로 받는다**(약하게 움직여도 되면 피로가 준다). 속도 증강(newtcnrotwarp)을 채택하고 약한 동작은 학습·평가에 모두 넣는다. 검출률은 요약에서 따로 본다.
같은 날 결정이 두 번 바뀌었다. 아래는 그 경과다.

처음 규칙: 약한 제스처는 명령으로 받지 않아도 된다.
기준: 복귀 피크 세기 < 같은 방향 중앙값의 **0.6배**. 중앙값은 방향 클립 294개 기준 UP 457, DOWN 444, LEFT 227, RIGHT 202 dps다(방향마다 정상 세기가 달라 방향별로 잰다). 목록: `data/annotations/ble-v2/weak-gestures.json`.
1) 학습과 평가에서 모두 뺐다. 같은 PC에서 비교하니 학습에서 빼면 남은 클립의 무발행이 늘어(S-P5 E20 25 → 66건) 2) 학습에는 다시 넣고 평가에서만 뺐다. 3) 이후 약한 동작도 조작으로 받기로 해 평가에도 다시 넣었다. NONE으로 학습하지 않은 이유는 0.6배 바로 위 정상 동작과 경계가 너무 가까워서다.
약한 동작에서도 모델은 다른 방향을 발행하지 않았다(정답 발행 또는 무발행).

| 세션 | 클립(복귀 세기 배율) |
|---|---|
| P1 | up.6 (0.45), up.7 (0.40), up.8 (0.36), up.9 (0.56), down.7 (0.57), down.8 (0.55), down.10 (0.59), down.11 (0.55), right.2 (0.51), right.5 (0.50) |
| P2 | right.1 (0.55), right.2 (0.58) |
| P3 | up.10 (0.54) |

- 주의: 기준은 S-P5 P1 fold의 무발행 클립 7개를 본 뒤 정했다. 그중 6개가 걸린다. 목록은 약한 동작 검출률을 따로 보는 데만 쓴다.
- 속도 증강 효과(zoon-pc 결과, 약한 동작만): S-P5 정검출 60.0%(newtcnrot E20) → 78.5%(newtcnrotwarp E40), C 92.9 → 92.9%.
