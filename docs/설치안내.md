# Windows 개발환경 설치

작성/공식 링크 확인: 2026-09-14. 설치 실행 및 업로드는 아직 미완료.

## 1. Arduino IDE 설치
공식 페이지: https://www.arduino.cc/en/software/

Arduino IDE 안정판의 Windows 64-bit 실행 설치 파일을 받는다.
확인 시점 버전: 2.3.10. 파일: `arduino-ide_2.3.10_Windows_64bit.exe`.

직접 다운로드:
https://github.com/arduino/arduino-ide/releases/download/2.3.10/arduino-ide_2.3.10_Windows_64bit.exe

파일 실행 → 설치 화면에 따라 설치 → Arduino IDE 실행.

## 2. Seeed 보드 패키지 등록
File(파일) → Preferences(환경설정) → Additional Boards Manager URLs(추가 보드 매니저 URL)에 아래 주소 추가 후 OK.
이미 주소가 있다면 기존 항목을 유지하고 새 항목으로 추가한다.

```text
https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json
```

JSON을 수동 다운로드하는 것이 아니라 위 URL을 IDE 설정에 입력한다.

## 3. 보드 코어 설치
Tools(도구) → Board(보드) → Boards Manager(보드 매니저).
`seeed nrf52` 검색 → `Seeed nRF52 Boards` 설치.
초기 BLE PoC에서는 mbed-enabled 패키지가 아닌 non-mbed 패키지를 사용한다.
이름에 추가 표시가 붙으면 `mbed-enabled` 포함 여부로 구분한다.
설치한 버전은 진행기록에 남긴다.

## 4. 보드와 포트 선택
Tools → Board → Seeed nRF52 Boards → Seeed XIAO nRF52840 Sense.
Tools → Port에서 보드 포트 선택.
사전 조회에서는 COM3를 확인했으나 XIAO 여부는 미확인. 보드를 분리/재연결했을 때 사라지고 나타나는 포트로 확인한다. 포트 번호는 바뀔 수 있다.

## 5. 최초 동작 검증
File → Examples → 01.Basics → Blink → Upload(오른쪽 화살표).
업로드 완료 로그와 실제 내장 LED 점멸을 모두 확인한다.
결과, IDE/코어 버전, 포트, 오류가 있다면 원문을 진행기록에 추가한다.

공식 설정 절차: https://wiki.seeedstudio.com/XIAO_BLE/
