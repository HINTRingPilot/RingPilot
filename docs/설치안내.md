# Windows 개발환경 설치

최종 갱신: 2026-09-22. 현재 PC에서 Arduino 펌웨어와 Android 디버그 APK 빌드까지 확인했다.

## 1. Arduino IDE 설치
공식 페이지: https://www.arduino.cc/en/software/

Arduino IDE 안정판의 Windows 64-bit 실행 설치 파일을 받는다.
확인 시점 버전: 2.3.10. 파일: `arduino-ide_2.3.10_Windows_64bit.exe`.

직접 다운로드:
https://github.com/arduino/arduino-ide/releases/download/2.3.10/arduino-ide_2.3.10_Windows_64bit.exe

파일 실행 → 설치 화면에 따라 설치 → Arduino IDE 실행.

## 2. Seeed 보드 패키지 등록
File(파일) → Preferences(환경설정) → Additional Boards Manager URLs(추가 보드 매니저 URL)에 아래 주소 추가 후 OK.
이미 주소가 있다면 기존 항목을 유지하고 새 항목으로 추가한다.

```text
https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json
```

JSON을 수동 다운로드하는 것이 아니라 위 URL을 IDE 설정에 입력한다.

## 3. 보드 코어 설치
Tools(도구) → Board(보드) → Boards Manager(보드 매니저).
`seeed nrf52` 검색 → `Seeed nRF52 Boards` 설치.
초기 BLE PoC에서는 mbed-enabled 패키지가 아닌 non-mbed 패키지를 사용한다.
이름에 추가 표시가 붙으면 `mbed-enabled` 포함 여부로 구분한다.
이 저장소에서 검증한 버전은 non-mbed `1.1.13`이다. `Seeed nRF52 mbed-enabled Boards`와 혼동하지 않는다.

## 4. 보드와 포트 선택
Tools → Board → Seeed nRF52 Boards → Seeed XIAO nRF52840 Sense.
Tools → Port에서 보드 포트 선택.
현재 PC에서는 XIAO가 COM6으로 확인됐다. COM3/COM4는 Bluetooth 직렬 포트이므로 사용하지 않는다. 재연결 시 포트 번호는 바뀔 수 있다.

## 5. 최초 동작 검증
File → Examples → 01.Basics → Blink → Upload(오른쪽 화살표).
업로드 완료 로그와 실제 내장 LED 점멸을 모두 확인한다.
결과, IDE/코어 버전, 포트, 오류가 있다면 원문을 진행기록에 추가한다.

공식 설정 절차: https://wiki.seeedstudio.com/XIAO_BLE/

## 6. RingPilot 펌웨어

`firmware/ble_poc/ble_poc.ino`를 열고 업로드한다. 시리얼 모니터는 115200 baud를 사용한다.

- `W/A/S/D`: 포인터 이동
- `C`: 클릭
- `U/J/L/R`: 위/아래/왼쪽/오른쪽 스와이프 BLE 명령
- `?`: 연결 및 알림 구독 상태

업로드 포트를 열 수 없으면 XIAO의 RST 버튼을 빠르게 두 번 눌러 부트로더 모드로 전환하고 새 COM 포트를 선택한다.

## 7. Android 개발환경

스와이프 앱을 수정하거나 APK로 빌드할 때만 필요하다.

1. Android Studio를 설치한다. 현재 PC 확인 버전은 `2026.1.4.7`이다.
2. 저장소의 `android/` 폴더를 프로젝트로 연다.
3. SDK Manager에서 Android SDK Platform 35, Android SDK Build-Tools 36.0.0, Android SDK Platform-Tools를 설치한다.
4. 별도 Java 설치는 필요 없다. Android Studio에 포함된 JDK를 사용한다.
5. 프로젝트에 포함된 Gradle Wrapper로 빌드한다.

```powershell
cd android
.\gradlew.bat :app:assembleDebug
```

APK 출력:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

현재 PC에는 자동화용 SDK가 저장소의 `.tools/`에 별도로 설치되어 있다. 이 폴더와 `android/local.properties`는 로컬 전용이며 Git에 포함하지 않는다.

## 8. Galaxy S10 USB 연결

1. 휴대폰의 설정 → 휴대전화 정보 → 소프트웨어 정보에서 빌드 번호를 7회 눌러 개발자 옵션을 연다.
2. 개발자 옵션에서 USB 디버깅을 켠다.
3. 데이터 통신 가능한 USB 케이블로 PC에 연결한다.
4. 휴대폰에 표시되는 이 PC의 USB 디버깅 허용 창을 승인한다.
5. `adb devices -l`에서 상태가 `device`인지 확인한다. `unauthorized`면 휴대폰 승인 창을 확인한다.

앱 설치 후에는 Android 설정 → 접근성 → 설치된 앱에서 `RingPilot 스와이프`를 사용으로 설정해야 한다.
