# RingPilot 하드웨어 제작 보고서

- **기록 버전:** v0.2 (v0.1 작성 2026-10-18, 8절 결과 갱신 2026-10-23)
- **작성 기준일:** 2026-10-18
- **기록 범위:** 초기 부품 확인부터 5-way 스위치·배터리 연결과 전원 동작 확인까지
- **현재 상태:** 스위치 5개 입력과 배터리 구동, 센터 버튼 System OFF를 확인했다(8절). 멀티미터 검사, 절연·최종 조립, 방향별 핀 매핑(센터=D1 외)은 미완료.

## 1. 프로젝트 목표

손가락에 착용하는 스마트폰 조작용 컨트롤러 제작. 엄지 조작용 5-way 스위치와 XIAO nRF52840 Sense의 IMU 제스처 입력을 사용하고 BLE로 스마트폰에 명령을 보낼 계획이다. 별도 물리 전원 스위치는 생략하고, 중앙 클릭을 제스처 인식 ON/OFF 등 펌웨어 기능으로 활용하기로 했다. 이는 설계 계획으로, 아직 동작 검증된 기능은 아니다.

## 2. 확인된 하드웨어

| 구분 | 구성 |
|---|---|
| 제어 보드 | Seeed Studio XIAO nRF52840 Sense, 무핀헤더 보드 |
| 입력 스위치 | ALPS Alpine SKRHACE010, 4방향+중앙 클릭 |
| 배터리 | Li-Po 401020, 사진 라벨 기준 55mAh, 커넥터 장착 |
| 전선 | 30AWG 연선 |
| 납 | Sn63/Pb37 유연납, 0.5mm |
| 판재 및 착용부 | ABS 판재 2mm·1mm, 벨크로, 양면테이프 등 |
| 납땜 장비 | KDsafe KD-T12C 계열 T12 인두·스테이션, 금속 거치대, 팁 청소 스펀지 |
| 작업판 | 사각 스테인리스 트레이 |

## 3. 스위치 ↔ XIAO 배선 설계

| 스위치 단자 번호 | 기능 | XIAO 연결 |
|---|---|---|
| 1 | A | D0 |
| 2 | Center | D1 |
| 3 | C | D2 |
| 4 | B | D3 |
| 5 | Common | GND |
| 6 | D | D6 |

배터리는 XIAO 후면 **BAT+**, **BAT-** 패드에 연결했다(2026-10-18). 5개 입력이 모두 GPIO에서 반응하는 것은 확인했지만, 단자 A~D가 실제 어느 방향인지는 센터(D1)만 확인했다.

## 4. 진행 이력

1. 컨트롤러, 스위치, 55mAh 배터리, 판재, 전선, 납땜 장비 등 실물 부품 수령 및 확인.
2. 벨크로와 ABS 판을 이용해 착용부 임시 배치. 보드의 최종 접착/조립은 보류.
3. 인두 스테이션 세팅, 금속 거치대·스테인리스 트레이 사용. 30AWG 전선 두 가닥 납땜 실습.
4. SKRHACE010 스위치의 6개 단자에 전선 직접 납땜.
5. 스위치에서 나온 전선을 XIAO의 D0, D1, D2, D3, D6 및 GND 위치에 연결.
6. 앞면 및 뒷면 배선 사진 촬영.
7. (2026-10-18) 배터리 없이 USB로 `firmware/switch_test` 실행, 5개 입력 확인. 이후 배터리 연결, `firmware/battery_test`로 배터리 단독 구동 확인.
8. (2026-10-18~23) `firmware/power_off_test`와 `imu_ble_stream`에서 센터 길게 누름 System OFF·재기동 확인.
   (시험 스케치 `switch_test`·`battery_test`·`power_off_test`는 2026-11-05에 지웠고 커밋 `05c4cb3` 이전 이력에 있다.)

## 5. 관찰된 문제·주의사항

- **패드 표면 변색:** D0 작업 후 인접 패드에서 흰색/은색 흔적 발견. 플럭스 잔여물인지 납 부착인지 미확정.
- **납땜 품질 미검증:** 일부 접합부에 납이 뭉친 모습과 노출된 도체가 관찰됨. 육안 사진만으로 전기적 접촉 또는 단락 여부를 단정할 수 없음.
- **전선 기계적 보호:** 전선 루프가 길고 작은 스위치 단자에 힘이 걸릴 수 있어 절연 및 당김 방지 고정이 필요함.
- **멀티미터 부재:** 연결 연속성 및 인접 패드의 단락 여부를 아직 측정하지 못함.
- **55mAh 배터리 충전 안전:** Seeed 공식 자료에 따르면 XIAO nRF52840의 충전 전류는 약 50mA 또는 100mA로 설정 가능하다. 펌웨어는 낮은 쪽(50mA로 추정, 미측정)을 쓴다. 셀의 허용 충전 전류를 확인하지 못한 상태에서 사용자 판단으로 USB 충전을 진행하고 있으며, 충전 중에는 발열·팽창을 관찰한다.
- **충전 중 자동 기동:** nRF52840은 USB 전원이 들어오면 System OFF에서 깨어나므로, 꺼둔 채 충전해도 펌웨어가 동작한다. Seeed 문서의 권고에 따라 펌웨어는 켜져 있는 동안 P0.14(`VBAT_ENABLE`)를 LOW로 둔다.
