작성: 2026-10-27. 기준 커밋 `dd4ae11`. 같은 날 검토 2회를 반영해 개정했고, 단계 1 채택 뒤 §7을 다시 개정했다(§12). **계획 문서이며 실행 기록은 `docs/experiments/ble-v2/return-label-01/README.md`와 `docs/진행기록.md`에 있다.**

**목표:** 증강 없이 학습하는 현재 최선 조건(newtcnrt)에 학습 데이터 증강을 하나씩 더해, 세션 간 일반화 개발 지표(S-P5 교차검증)의 정검출이 오르는지 확인한다.

**접근:** 지금까지와 같이 한 번에 요인 하나만 바꾼다. 데이터·분할·라벨·채점·발행 규칙·E 선택 규칙은 그대로 두고, fold의 학습 원본에만 증강 사본을 더한다. 채택 기준은 결과를 보기 전에 이 문서에 고정한다.

**실행 순서:** 문제 정의 수정(이 개정) → 단계 0 데이터 동일성 확인 → 같은 환경의 기준선 → 단계 1 회전 단독 비교 → 단계 2 속도 설계 점검 → (점검 통과 시) 속도 비교. 3차 개정: 단계 1 채택 뒤 단계 2는 newtcnrot 위 회전 + 속도 비교(§7).

## 1. 출발점

### 1.1 지표가 가리키는 자료

- **S-P5 수치는 P5 자세의 성능이 아니다.** `v2_return.py`는 분할의 `cv.folds`만 돌린다. S-P5 분할의 fold는 P1~P4를 한 세션씩 검증으로 돌리는 세션 단위 교차검증이며, 검증 원본은 P1~P4의 269개(방향 237, 배경 32)다. P5 원본 67개(분할의 평가용)는 S-P5 실행에 쓰이지 않는다. 따라서 S-P5 수치는 "학습에 없던 세션에 대한 개발 지표"이며 "P5에서 개선됐다"고 쓰지 않는다.
- **C 교차검증에는 P5가 들어 있다.** C fold의 검증 원본 266개(방향 236) 중 53개가 P5다. 프로젝트 전체에서 P5가 미사용 자료이거나 독립 최종 평가용으로 남아 있는 것은 아니다.
- 두 분할 모두 개발용 교차검증이며 독립 최종 평가가 없다.

## 2. 보존할 것과 원칙

- 기존 데이터·주석·분할·`protocol.json`·결과·요약·로그를 덮어쓰지 않는다. `v2.PROTOCOL_CONDITIONS`도 그대로 둔다(학습 전 1회 저장한 v2 프로토콜 기록). 증강 설정은 `v2_return.py`의 조건 표에 두어 결과 JSON의 `condition`에 기록되게 한다.

- 원본 클립(원시 단위: m/s², deg/s) 단계에서 증강하고, 그 뒤 창 자르기·정규화·회전각 계산을 한다.
- 정규화 평균·표준편차(6축)는 지금처럼 원본 학습 클립으로만 계산한다. 회전각 정규화(`normalize_angle`)는 지금처럼 선택된 학습 창으로 계산하므로 사본이 포함된다(학습 데이터만 사용).
- 회전각 영점은 지금 newtcnrt 전처리와 같게, **증강된 raw의 0–890 ms 축별 중앙값으로 다시 추정**한다. 실제 기기도 회전된 신호로 영점을 추정하므로 추론 조건과 맞는다.
- 증강 사본을 만들지 않는 클립도 원본은 학습에 그대로 남긴다.
- 새 결과는 기존과 같은 `docs/experiments/ble-v2/return-label-01/` 아래 새 조건 이름으로 저장한다.

### 3.1 실행 환경 통일과 기록

### 3.2 채택 기준(결과 보기 전 고정)

비교 대상은 같은 환경의 newtcnrt 재실행. 각 조건의 선택 E(기존 규칙: seed 평균 selection_score 최대, 같으면 작은 E)를 쓴다. 통계적으로 정해진 기준이 아니라 이번 실험을 위한 실무 기준이다.

| 지표 | 기준 |
|---|---|
| S-P5 정검출(`clean_success_rate`) | seed 평균 **+1%p 이상**, 같은 seed끼리 비교해 **5개 중 4개 이상 개선** |
| C 정검출 | 기준 **평균 대비 감소 1%p 이내** |
| 배경 오발행(클립당) | 두 분할 모두 **기준 평균 이하** |
| S-P5 무발행 비율 | **기준 평균 이하** |

- 모두 만족할 때만 채택한다. 못 미치면 채택하지 않고 기록·결과는 남긴다.
- 5개 중 4개 개선은 학습의 일관성을 보는 기준이다. 같은 자료로 학습한 결과들이므로 독립적인 일반화 입증으로 해석하지 않는다.

사본 2개면 학습 원본이 3배라 같은 E에서도 업데이트가 약 3배다. 판정은 §3.2대로 선택 E로 하되, 다음을 함께 보고한다.

- fold별 실제 업데이트 수(= 에폭 × ⌈학습 창 수 / 16⌉)를 결과 JSON에 기록한다.
- 같은 E 비교(E20·E60)와 함께, 업데이트 수가 비슷한 지점끼리 비교(증강 E10 대 기준 E30, 증강 E20 대 기준 E60)를 보고한다. 이 비교들은 판정에 쓰지 않는다.

## 6. 단계 1 — 회전 증강(newtcnrot)

### 조건

`"newtcnrot": {**newtcnrt, "aug": {"kind": "rotate", "rot_y_deg": 30, "tilt_deg": 15, "copies": 2}}`

- 회전행렬 R = R_tilt · R_y(θ). θ ~ U(−30°, +30°). R_tilt는 X-Z 평면 안의 임의 축(방향각 ~ U(0°, 360°))으로 φ ~ U(−15°, +15°) 회전.
  - Y축 중심은 UP/DOWN(gyrY)을 보존하면서 측정된 좌우 축 차이(약 25–30°)를 덮는다. 기울기 ±15°는 UP/DOWN의 기울기(5–20°)와 RIGHT의 Y 쪽 기울기를 일부 덮는 보수적 범위다.
- 적용: b = 원본 raw 자이로 0–890 ms 축별 중앙값. `gyro' = R·(gyro − b) + b`, `acc' = R·acc`. 영점은 센서 고유 성질이라 회전하지 않는다. 가속도는 중력까지 함께 돌린다(센서 좌표계 전체가 돈 상황).
- 회전각 채널의 영점은 §2대로 `gyro'`에서 다시 추정한다. 축별 중앙값은 회전과 교환되지 않으므로 다시 추정한 값은 b와 조금 다를 수 있다.
- 대상: fold의 학습 원본 전체(방향 + idle/other). 배경도 같이 돌려야 "회전된 신호 = 동작 클립"이라는 지름길이 생기지 않는다.
- 사본 2개 + 원본 → 학습 원본 3배. 양성 창이 3배가 되므로 `choose_training`이 고르는 NONE 수도 3배가 된다(종류별 라운드로빈 규칙 그대로).

### 사전 점검 결과(실제 사본 생성 설정, 읽기 전용, 2026-10-27)

위 설정(기울기 포함, 클립 경로 해시 고정 난수, 사본 2개)으로 모든 클립에서 회전 후 영점을 다시 추정해 b와 비교했다(축 최대 차이).

| 대상 | 사본 수 | 중앙값 | p90 | 최대 | 2 dps 초과 |
|---|---|---|---|---|---|
| 방향 클립 | 592 | 0.09 | 0.40 | 5.83 | 4 |
| 배경 클립 | 80 | 0.25 | 2.87 | 11.89 | 12 |

이 값은 실제 영점 오차가 아니라 **추정기 값이 회전 때문에 얼마나 달라졌는지**를 보는 지표다. 배경 클립은 0–890 ms가 정지 상태가 아닌 경우가 많아 원본에서도 중앙값이 영점을 대표하지 않는다. 회전 실험 준비는 진행한다. 실제 구현의 생성 코드로 같은 분포를 다시 산출해 결과와 함께 보고한다.

### 테스트

수식 검사와 추정기 영향 측정을 나눈다. 허용 오차를 넓혀 통과시키지 않는다.

- 수식 검사(알려진 영점 b 사용)
  - [ ] 단위행렬 R이면 사본 raw가 원본 raw와 같다.
  - [ ] 각 시점의 |acc|, |gyro − b|가 보존된다(부동소수점 허용 오차).
  - [ ] b를 그대로 쓰면 사본의 누적 회전각 = R·(원본 누적 회전각)이다.
- 추정기 영향 측정(합격·불합격 판정 아님)
  - [ ] 실제 중앙값 추정기를 사본에 다시 적용했을 때 영점 추정값 차이와, 창 끝 회전각 차이의 분포(중앙값·p90·최대)를 방향/배경으로 나눠 결과에 기록한다.
- 데이터 처리
  - [ ] 사본의 라벨·`none_group`이 원본과 같다.
  - [ ] 검증 청크에 `#` 사본이 없다.
  - [ ] 같은 클립·사본 번호는 fold와 무관하게 같은 R을 받는다.

### 실행

- [ ] `run-all --labels newtcnrot`로 C·S-P5 × seed 5 = 10회, `summarize --out summary-aug-rot.json`.

## 7. 단계 2 — 회전 + 속도(newtcnrotwarp, newtcnrot 기준)

3차 개정(2026-10-27): 단계 1(newtcnrot)이 채택돼 기준이 바뀌었다. 사용자 결정으로 속도는 newtcnrt 단독 비교가 아니라 **newtcnrot의 회전 사본에 속도를 더해 newtcnrot과 비교**한다. 이 비교로 알 수 있는 것은 "회전에 속도를 더한 효과"이며, 속도 단독 효과와 두 증강의 상호작용은 분리하지 않는다(분리하려면 속도 단독·결합 조건이 더 필요하다). 단계 3(§8)은 이 비교로 대신한다.

### 7.1 폐기한 설계와 이유

- **r 고정점 + 앞쪽 첫 샘플 반복 패딩(초안):** s = 0.8에서 앞쪽 400–480 ms가 첫 샘플 반복으로 채워졌고, 0–890 ms 영점 추정값이 296개 중 158개에서 2 dps 넘게 바뀌었다(중앙값 2.17, p90 13.2, 최대 178.6 dps). 검토에서 확인한 사례는 동작 시작 1,640 ms(변형 후 1,736 ms, 기존 가드 통과)인데 Y축 영점이 −3.57 → −51.39 dps가 됐다.
- **기존 가드의 역할:** 변형 후 동작 시작은 `r + s·(start − r)`이다. s > 1이면 시작이 앞당겨져 영점 구간을 침범할 수 있고 가드는 이를 막는다(방향은 맞다). s < 1의 앞쪽 패딩은 별개 문제라 가드로 막을 수 없다.
- **반사 패딩:** `main_motion_start_ms` 앞이 정지 상태라는 보장이 없어 이전 움직임을 복제할 수 있고, 뒤쪽 반사도 남은 복귀 동작을 복제할 수 있다. 채택하지 않는다.
- **890 ms 샘플부터 변형(2차 개정 후보):** 영점은 0–890 ms(90행) 중앙값인데 890 ms 샘플에 배율이 들어가 회전 사본 546개 중 33개의 영점이 바뀌었다(최대 0.035 dps). 값 변형은 900 ms부터로 고친다.
- **"동작 시작 < 900 ms 23개 + |g(890) − b| > 8 dps 22개 제외"로 경계 점프 ≤ 2 dps를 보장(3차 개정 검토 초안):** 원본 축별 값 기준이라 회전 뒤에는 성립하지 않는다(통과 사본 502개 중 2개가 최대 2.36 dps). 사본마다 실제 회전·s로 검사한다.

### 7.2 설계

`"newtcnrotwarp": {**newtcnrot, "aug": {"kind": "rotate_warp", "rot_y_deg": 30, "tilt_deg": 15, "copies": 2, "anchor_ms": 890, "scale_min": 0.8, "scale_max": 1.25, "max_jump_dps": 2.0}}`

- 사본 c마다 `rng = clip_rng(원본 경로, c)`에서 **회전을 newtcnrot과 같은 순서로 먼저 뽑고**(같은 R), 그다음 s ~ 로그 균등(0.8, 1.25)을 뽑는다. 사본 이름도 newtcnrot과 같은 `#rot1`·`#rot2`로 둬 `choose_training`의 클립 순서를 바꾸지 않는다.
- 회전 사본 `rot = rotate_raw(raw, R, b)`(b = 원본 0–890 ms 자이로 축별 중앙값, §6과 같음)에 속도 변형을 더한다. 회전과 속도 변형은 순서와 무관하다(실측 최대 차이 5.7e-14).
- 속도 변형(사본 시각 t′, 10 ms 격자):
  - t′ ≤ 890 ms(0–89행): 회전 사본 그대로(비트 단위 동일, 사본 영점 = newtcnrot 사본 영점).
  - t′ ≥ 900 ms: 시각 대응 `src = 890 + (t′ − 890)/s`(890 ms 고정점)의 회전 사본 값을 축별 선형 보간. 자이로는 `(보간값 − b)/s + b`, 가속도는 보간만(선가속도 1/s² 무시 — 한계).
  - src > 3,990 ms인 행부터는 원본 범위 밖이다. valid_rows = src ≤ 3,990 ms인 행 수로 넘겨 그 행을 포함하는 판정 창을 학습에서 뺀다(`v2.augment_chunks`). 범위 밖 행은 마지막 유효 행 값으로 채운다(창이 빠지므로 학습에 쓰이지 않음).
  - 라벨 시각: record 사본의 `completion_ms = r′ = 890 + s·(r − 890)`(r = 새 e). 채점은 검증 원본만 쓰므로 바뀌지 않는다.
- **속도 적용 조건(모두 만족할 때만, 아니면 그 사본은 회전만 적용한 newtcnrot 사본 그대로):**
  - 방향 클립(배경은 속도 개념이 없어 회전만).
  - `main_motion_start_ms` ≥ 900 ms(`data/annotations/ble-v2/*-candidates.json`).
  - 양성 창 보존: 변형 사본의 유효 구간 안 양성 창 수 = 원본 양성 창 수(r′가 첫 판정 1,590 ms 앞으로 당겨지거나, r′+150이 3,990 ms 또는 s < 1의 유효 끝 890 + 3,100s ms를 넘어 창이 줄면 회전만). 구현 검토에서 처음의 "r′ + 150 ≤ 3,990 ms" 조건이 s < 1의 유효 끝과 첫 판정 앞 당김을 놓친다는 것을 찾아 바꿨다(현재 데이터에서는 해당 사본 0).
  - 경계 점프 ≤ 2 dps: 회전 사본·실제로 뽑힌 s·영점 b로 첫 변형 샘플(900 ms)에서 `max_axis |보간값(src(900)) − b| · |1/s − 1|`. 2 dps는 실무 기준이다. 영점 오차 시험(2 dps에서 영향 작음)은 참고일 뿐 경계 점프가 무해하다는 근거로 쓰지 않는다.
- 사본 수는 newtcnrot과 같다. 그러나 s < 1이면 r′가 첫 판정(1,590 ms) 앞으로 당겨져 양성 창이 줄 수 있고 범위 밖 창이 빠지므로, **선택되는 창 수와 업데이트 수는 같다고 가정하지 않는다**(§7.4에서 학습 전에 확인).

## 8. 단계 3 — 조건부 결합

3차 개정으로 §7이 회전 + 속도를 newtcnrot과 직접 비교하므로 따로 실행하지 않는다. 세기 변형은 이번 계획에서 실행하지 않는다.

## 9. 하지 않는 것

- 자이로 영점 오프셋 섞기: 사용자 결정(2026-10-27)으로 하지 않는다. 회전·속도 증강에서도 영점에 임의 오차를 넣지 않는다.
- 좌우 뒤집기로 LEFT↔RIGHT 만들기: 중력·장착 비대칭 때문에 물리적으로 맞지 않는다.
- mixup/cutmix, 라벨 시각을 고치지 않는 시간 이동: 정답 시각의 의미를 깨뜨린다.
- 앞·뒤 첫/마지막 샘플 반복 패딩, 반사 패딩(§7.1).
- 중력 방향 교체 증강, 가속도 채널 제외 진단: 이번 범위 밖. 증강 결과가 미미하면 다음 후보로 검토한다.
- 데이터·분할·라벨·채점·발행 규칙·E 후보·E 선택 규칙 변경, seed 확대, 펌웨어 작업.

## 10. 보고와 기록

- 조건별로 선택 E, 정검출, `success_rate`, 무발행, 조기 발행 클립, 가는 피크~끝점 반대 방향 조기 발행 건수, 배경 오발행, 지연 중앙값을 seed별 값과 평균·범위로 보고한다. 같은 seed끼리 차이도 함께 적는다.
- §3.3의 업데이트 수와 비교들, 학습 시간(fold당 초), 사본·생략·제외 창 수, 회전 추정기 영향 분포, `env`를 기록한다.
- S-P5 수치는 "P1~P4 세션 교차검증"으로 표기한다(§1.1).
- `docs/experiments/ble-v2/return-label-01/README.md`에 조건별 절을 추가하고 `docs/진행기록.md`에 날짜·목적·변경·이유·검증·결과·다음을 남긴다(AGENTS.md).
- 진행기록은 메인 체크아웃과 이 워크트리 양쪽에 따로 추가된 내용이 있다. 병합할 때 양쪽 추가 내용을 모두 보존하고, 한쪽 파일로 덮어쓰지 않는다.

## 11. 예상 비용

## 12. 개정 이력

- 초안(2026-10-27): 회전·속도 증강, r 고정점 속도 변형, 기준 조건 seed 최솟값·최댓값 기반 채택 기준.
