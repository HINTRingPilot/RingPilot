# V2 완료 주석 타당성 확인 및 다음 실험 선택 계획

> 실행 담당자: `executing-plans` 절차로 아래 체크 항목을 순서대로 수행한다. 이 문서는 계획이며, 코드 구현·촬영·추가 학습의 완료 기록이 아니다.

**목표:** 조기 발행의 원인을 완료 주석 오류로 단정하지 않고, 기존 자료의 시간 경계 학습과 독립적인 동작 관찰을 확인해 다음 단일 요인 실험을 정한다.

**접근:** 기존 v2 산출물은 고정한다. 먼저 저장된 센서·예측·발행 로그와 학습 창 구성을 분석한다. 이어 소량의 새 개발용 관찰 자료에서 영상과 센서를 동기화하고, 예측을 가린 상태로 사람이 표시한 복귀 완료 구간과 자동 후보를 비교한다. 이번 계획은 원인 진단까지이며 모델 설정을 바꾸거나 최종 평가를 실행하지 않는다.

**도구:** 기존 Python 3.12 가상환경, NumPy, 저장된 JSON/NPZ/CSV, 기존 완료 후보 도구. 파형은 정적 PNG 또는 HTML 보고서로 만들고 출력 라이브러리·버전을 기록한다. 새 관찰에는 센서와 손가락·복귀 동작을 볼 수 있는 영상 및 검증된 시각 대응이 필요하다.

**상태:** 2026-10-25 작성 / 실행 전. 코드 기준 커밋 `b7a2bd3`. 기존 72개 테스트 통과 사실은 진행기록의 독립 재검토에 있고, 이 계획 작성 중에는 재실행하지 않았다.

## 4. 작업 B — 기존 자료에서 파형과 시간 경계 학습 확인

### 표본 선택

- [ ] 296개 방향 원본에서 세션 P1~P5 × 방향 UP/DOWN/LEFT/RIGHT마다 1개를 추출한다. 그룹 안은 `source_path` 순으로 정렬하고, 그룹 순서도 위 순서로 고정해 `default_rng(20261025)`를 연속 사용한다. 기본 표본은 20개다.
- [ ] e−`main_motion_end_ms`가 큰 순서 상위 5개(동점은 `source_path` 오름차순), 끝부분 잘림 원본 P4 `raw_left.16`을 추가하고 중복을 제거한다. 최종 표본 수는 20~26개다. 추가 표본은 이상 사례 점검용이라고 표시한다.
- [ ] 표본 목록·선택 규칙·원본/주석 해시를 먼저 저장한다. 이 표본의 비율을 전체 성능이나 대표성의 추정치로 쓰지 않는다.

### 파형·예측·발행 표시

- [ ] 6축 원시 파형, 보조 자이로 크기, 자동 에너지 종료 시각, e, 양성 구간 `[e,e+150)`, 성공 허용 구간 `[e,e+500]`, 판정 점수와 발행을 같은 ms 축에 표시한다.
- [ ] 판정 시각은 저장된 창 목록의 마지막 실제 샘플 시각을 사용한다. 첫 판정 전 0~1580 ms 구간은 점수를 만들거나 앞선 값으로 채우지 않는다.
- [ ] 공통 진단 조건은 E=60, 기존 5 seed다. P1~P4 원본은 S-P5 보정에서 그 세션이 검증인 fold, P5 원본은 S-P1 보정에서 P5가 검증인 fold의 저장 예측을 사용한다. 모델이 그 원본을 학습하지 않았는지 목록으로 확인한다. 이 E는 진단용 고정 시점이며 기존 선택 E를 대체하지 않는다.
- [ ] 5 seed 예측의 범위와 seed별 발행을 표시한다. seed 평균 점수로 새 발행을 만들지 않는다. 각 발행은 원래 seed의 예측과 고정 후처리로 재현한다.
- [ ] 조기 발행은 방향 일치/불일치를 구분한다. 성공·조기·늦음·누락을 보고 실제 복귀 완료가 검증됐다고 기록하지 않는다.

### NONE 창의 실제 선택 확인

- [ ] 각 원래 fold의 **학습 부분만** 사용해 `choose_training()`의 고정 선택을 재현한다. 검증·평가용 원본은 선택 목록에 없어야 한다. 정규화와 학습 창 재구성은 해당 fold의 원래 규칙을 따른다.
- [ ] 완료 전 NONE을 e 기준 `[-300,0)` ms, `[-600,-300)` ms, 그보다 이른 구간으로 나눠 선택 전/후 수와 선택 비율을 기록한다. 완료 후 NONE·idle·other도 별도로 기록한다. 구간은 진단 집계용이며 라벨·성공 기준을 바꾸지 않는다.
- [ ] 원본별 복귀 말미 NONE이 하나도 선택되지 않은 개수와 세션별 분포를 기록한다. fold 간 원본 재사용은 반복 관측으로 표시하고 독립 표본 수처럼 합산하지 않는다.
- [ ] 선택 창 총수·클래스 수·NONE 종류별 수가 기존 config와 일치하는지 확인한다.

검사 항목: 같은 seed의 표본 재현, 원본 경계/미래 값 혼입 없음, 정규화·NONE 선택에 학습 부분만 사용, 저장된 창 시각/발행과 재현 결과 일치, 여러 발행을 한 클립으로 세는 집계, 출력 덮어쓰기 거부. 새 분석 검사를 먼저 실행하고 기존 경로에 영향이 있을 때 전체 72개 검사도 실행한다. 전체 검사 안의 짧은 학습은 코드 점검용으로 기록한다.

완료 조건: 표본 그림과 전체 fold의 NONE 분포가 재현되며, '시점 후보 문제'와 'NONE 학습 부족 가능성'을 구분해 기술할 수 있다. 이 단계에는 추가 모델 학습이 필요 없다.

## 5. 작업 C — 소량의 개발용 관찰 자료에서 독립 확인

### 준비 및 동기화 파일럿

- [ ] 실제 자연 복귀 완료를 **'의도한 방향 동작 후 자연 복귀가 끝나고, 다음 명령 전 휴지 상태로 들어가는 경계'**로 정의한다. 출발 자세와 똑같은 각도를 강제하지 않는다. 눈에 보이는 미세 떨림 때문에 경계를 하나로 정하기 어려우면 구간 또는 판정 불가로 남긴다.
- [ ] 손가락·손·필요한 팔의 복귀를 볼 수 있는 촬영 기기를 확보하고 실제 영상 FPS와 촬영 방향을 기록한다. 기존 v2 클립에는 동기화 영상이 없으므로 과거 클립의 정답을 영상으로 확인한 것처럼 처리하지 않는다.
- [ ] **우선 3개 파일럿만** 수집해 동기화·가시성·CSV 품질을 확인한다. 이 개수는 촬영 절차 점검용 제안이며 성능 검증 표본 수가 아니다.
- [ ] 센서 샘플 번호/시각에 연결된 영상에서 보이는 동기화 표식을 확보한다. 예: 보드의 동일 샘플 시계에 기록한 LED 표식을 촬영하고 별도 sidecar에 표식의 샘플 시각과 영상 프레임을 남긴다. 정확한 연결이 없는 앱 비프·화면의 '지금' 표시만으로 CSV 0 ms를 정하지 않는다.
- [ ] 기존 앱의 시작 비프는 `startCapture()` 호출 부근이고 CSV 0 ms는 첫 수신 슬롯을 기준으로 하므로 둘의 일치를 가정하지 않는다. 위 표식이 현재 펌웨어/앱에서 제공되지 않으면 동기화 기록 방식의 별도 구현·검증이 선행 작업이다. 이 계획 작성 단계에서 제공된다고 간주하지 않는다.
- [ ] 관찰 영상의 앞/뒤 시각 대응을 확인하고 offset·드리프트·오차 범위를 기록한다. 분리된 표식은 분석할 4초 클립 밖에 두거나, 표식용 기록과 제스처 클립의 관계를 명시해 자동 완료 도구의 에너지 계산을 오염시키지 않는다.
- [ ] 실무상 파일럿 목표는 시간 대응의 최대 불확실성 50 ms 이내다(현재 판정 간격에서 정한 작업 목표이며 검증된 정답 허용치가 아님). 충족하지 못하면 본 관찰로 확대하지 않고 동기화를 보완한다. 실패 자료는 정성 관찰로만 남기며 정답 시각 수정 근거로 사용하지 않는다.

파일럿 완료 조건: 센서 CSV와 영상의 시각 대응을 재현할 수 있고, 동작·자연 복귀가 보이며, 동기화 오차를 수치로 설명할 수 있다. 추가 기기·동기화 구현이 필요한 경우 사용자 수행 항목으로 분명히 남긴다.

### 본 관찰과 사람 주석

- [ ] 파일럿 통과 후 P1~P5 × 4방향 × 1회, 우선 20개를 개발용으로 관찰한다. 실행 순서는 seed 20261025로 고정하고 센서 조건은 기존 100 Hz·4초·1초 신호·±2000 dps를 따른다. 이 수집량은 초기 진단 제안이며 최소 필요량이나 성능 검증 규모가 아니다.
- [ ] 사람은 모델 예측·발행·자동 e를 가린 영상에서 먼저 복귀 완료의 가능한 구간을 표시한다. 가능하면 두 명이 독립 표시하고, 한 명이면 순서를 바꾼 두 차례 표시라는 한계를 기록한다. 동작이 안 보이면 판정 불가로 남긴다.
- [ ] 영상 프레임 구간을 센서 시간으로 변환하고 동기화 불확실성을 포함해 `[human_lo_ms,human_hi_ms]`를 저장한다. 관찰자 간 불일치도 숨기지 않는다.
- [ ] 사람 구간을 저장한 뒤 기존 도구의 자동 e를 계산해 공개하고, e가 구간 안/앞/뒤인지 비교한다. 같은 센서 도구의 에너지 종료점은 독립 정답으로 세지 않는다.
- [ ] 새 자료에 과거 모델을 적용할 필요가 생겨도 사람 주석을 먼저 고정한다. 기본 계획에는 새 모델 학습이나 새 자료 추론이 필요 없다. 기존 모델 가중치가 저장돼 있다고 가정하지 않는다.

주석 필드: `source_path`, `video_path`, 센서·영상 해시, 실제 FPS, 동기화 표식·변환·불확실성, `observer_id`, `human_lo_ms`, `human_hi_ms`, `unrateable_reason`, 자동 `completion_ms`, 공개 순서, 도구/앱/펌웨어 버전, 용도 `development_diagnostic`.

완료 조건: 판정 가능한 수/전체 수, 사람 구간과 e의 관계, 세션·방향별 관찰, 시각 오차와 가시성 한계를 보고한다. 20개를 새로운 일반화 성능 평가나 기존 296개 주석의 정확도 검증으로 확대 해석하지 않는다.

## 7. 독립 최종 평가와 이번 단계의 종료

- [ ] 기존 336개와 위 파일럿/관찰 자료는 모두 개발에 사용된 자료로 명시한다.
