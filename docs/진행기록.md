# 스마트링 개발 진행 기록

포트폴리오 작성에 사용할 사실 기반 개발 일지. 날짜는 한국 시간 기준.
각 작업마다 목적 → 수행 내용 → 선택 이유 → 검증 결과/증거 → 문제와 해결 → 다음 작업을 기록한다.
계획, 실제 수행, 사용자 확인을 구분하고 미검증 성능을 성과로 쓰지 않는다.
버전, 오류 원문, 관련 코드 경로, 측정 조건과 결과도 확보되는 대로 남긴다.

- Arduino 설정 및 LED Blink 동작: 사용자 확인으로 완료.
- 다음 확인: 앱 재실행 조건에서 HID 동작 유지 여부. 이후 스틱 입력 또는 Android 최소 제스처 제어로 확장.

- BLE PoC 컴파일·업로드·USB 시리얼 응답·Galaxy S10 페어링 및 좌우 포인터 이동 검증 완료.

## 2026-09-14 — 기획 검토 및 개발환경 사전 점검

- Windows 시리얼 포트 조회에서 COM3 확인. 레지스트리 매핑은 `\Device\USBSER000 → COM3`.
- COM3 장치가 XIAO nRF52840 Sense인지는 아직 확인하지 못함.

### 진행 방향과 이유
- 초기 목표: 업로드 성공 → BLE HID 포인터 → Custom GATT 알림 동시 동작 → 재연결 검증.

- Android 최소 스와이프 검증을 AI보다 먼저 진행하도록 제안. 실제 대상 앱에서 조작 가능한지 조기에 확인하기 위함.
- 이후 방향 입력, IMU 수집, TinyML, 배터리, 착용 기구 순으로 확장 예정.

## 2026-09-14 — 설치 전 개발환경 선택 검토

- 사용자 질문: Arduino IDE가 일반적인 선택인지, STM32CubeIDE에 대응하는 Seeed 전용 환경이 있는지 확인 요청.
- 공식 문서 확인: Seeed의 XIAO 시작 안내는 Arduino IDE를 사용하며 PlatformIO 안내도 제공한다. Nordic은 nRF Connect SDK용 공식 IDE 환경으로 VS Code + nRF Connect 확장을 제공한다.
- 구분: Seeed는 해당 개발 보드 제작사, Nordic은 탑재 nRF52840 칩 제조사. 칩 제조사 SDK 관점의 대안은 nRF Connect SDK(Zephyr 기반).
- Arduino IDE와 Arduino 프레임워크는 별개 층이다. PlatformIO에서 Arduino 코드를 쓰는 것과 Zephyr로 프레임워크를 바꾸는 것은 변경 범위가 다르다.
- 권고: 빠른 통신 PoC에는 기존 Arduino/Bluefruit 경로가 적절하다. RTOS·BLE 내부 제어 학습을 주요 목표로 삼는다면 Nordic SDK 경로를 시작부터 고려할 수 있다.
- Zephyr 공식 문서에 XIAO BLE Sense 보드 및 UF2 업로드 경로가 존재함을 확인. 특정 nRF Connect SDK 버전에서의 보드 지원·부트로더/메모리 설정은 아직 검증하지 않음. 중단점 디버깅에는 SWD 연결 및 외부 디버거 구성이 필요하다.
- 상태: 비교 설명만 수행. 설치 실행이나 개발환경 변경 확정은 하지 않음.
- 다음 작업: 개발환경 방향에 따라 설치 및 첫 업로드 검증 진행.

## 2026-09-14 — 업로드 포트 소실 오류 진단

- 사용자 업로드 로그: 컴파일 성공 후 DFU 업로드에서 `Serial port could not be opened on COM3`, `FileNotFoundError(2)` 발생.
- precompiled nRFCrypto 안내는 실패 원인이 아니며, 실제 오류는 업로드 대상 COM3를 열 수 없다는 내용.
- 에이전트 재조회: SerialPort API에서 포트 없음. 권한 확장한 Arduino CLI `board list`도 `No boards found.`. 연결 가능한 COM 포트나 이동식 볼륨을 확인하지 못함.
- 따라서 현재 포트 번호만 바꿔 재시도할 수 없는 상태. 포트 소실의 근본 원인(USB 연결/실행 펌웨어/부트로더 전환 등)은 미확정.
- 공식 Seeed 문서의 RST 두 번 누르기 부트로더 진입 절차 확인: https://wiki.seeedstudio.com/XIAO-nRF52840-Zephyr-RTOS/
- 다음 작업: 사용자에게 USB 연결 상태 유지 및 RST 빠르게 두 번 누르기 요청. 인식 복구 후 에이전트가 포트 재조회 및 CLI 업로드 진행 예정.
- 현재까지 이번 오류 뒤 업로드 재시도나 부트로더 변경은 수행하지 않음.

## 2026-09-14 — Galaxy S10 페어링 및 HID 송신 확인

- 사용자: Galaxy S10에서 페어링 완료 보고.
- COM5 상태 조회: `Connected: 1`, `Notify subscribed: 0`. 보드 측 BLE 연결 확인, Custom GATT 알림 미구독.

- HID 송신 API 성공까지 확인했으며 휴대폰에서 실제 포인터 이동은 사용자 관찰 대기. 클릭은 전송하지 않음.
- 다음 작업: 사용자에게 실제 오른쪽 포인터 이동 여부 확인 후 나머지 방향/클릭 및 GATT 구독 검증 진행.
- 사용자 관찰: 화면 중앙에 포인터가 나타났으나 잠시 시선을 뗀 뒤 사라짐. 이동 여부는 확인하지 못함. 포인터 소실 원인은 미확정.

3. BLE HID + Custom GATT PoC 코드 및 테스트 안내 작성, 컴파일 성공.
4. COM3 소실 업로드 오류 진단. USB 재연결만으로는 복구되지 않았으나 사용자 RST 더블클릭 후 COM4 인식.
5. 에이전트 CLI 업로드 성공. 실행 포트 COM5에서 시리얼 상태 응답 확인.
6. Galaxy S10 / Android 12 페어링 성공 및 보드 Connected: 1 확인.
7. 좌우 HID 이동 명령 50회 송신 성공, 사용자 실화면 포인터 정상 이동 확인.
8. PC USB 명령 → 보드 → BLE HID → Android 포인터 처리 흐름 설명.

### 재개 시 참고
- 보드: Seeed XIAO nRF52840 Sense.
- 코어: Seeed nRF52 Boards(non-mbed) 1.1.13.
- 펌웨어: `firmware/ble_poc/ble_poc.ino`.
- 테스트 안내: `docs/BLE테스트.md`.
- BLE 이름: `SmartRing-PoC`.
- 마지막 실행 포트: COM5. 재연결 후 달라질 수 있으므로 먼저 조회.
- 시리얼: 115200 baud. `?` 상태, WASD 이동, C 클릭.
- 마지막 확인에서 알림 구독은 0. Custom GATT 코드는 있지만 수신 동작은 검증하지 않음.
- 오늘 마지막 시리얼 작업 후 포트를 닫았음. 별도 백그라운드 명령 송신을 실행하지 않음.

## 2026-09-20 — 재개 및 상하 포인터 이동 시험

- 사용자 보고: USB 및 휴대폰 Bluetooth 연결 완료. 자동 재연결 여부/소요 시간은 확인하지 않았으므로 재연결 시험 완료로 처리하지 않음.

- 결과: HID queued 응답 50개, failed/Not connected 응답 0개. 포트는 시험 후 닫음.

- 클릭 시험을 위해 사용자 계산기 앱 실행. 포인터가 입력 없을 때 보이지 않으며 현재 위치는 중앙 부근으로 추정한다는 보고. 실제 위치는 미확인.
- 위치 확인을 위해 3초 대기 후 D/A를 500ms 간격, 10주기 전송. 클릭은 아직 보내지 않음.
- 사용자 포인터 위치 확인: 퍼센트 버튼 부근. 사용자 요청에 따라 오른쪽 이동 3회 후 해당 위치 클릭 1회 진행.

- 클릭의 실제 계산기 반응은 사용자 확인 대기. 상대 이동 3회이며 버튼 3개를 건너뛰는 의미는 아님.
- 사용자 첫 클릭 시험에서 원하는 반응이 없다고 보고. 클릭 위치/계산기 상태/입력 처리 중 원인은 미확정.
- 사용자 요청으로 현재 위치에서 S 7회(300ms 간격) 후 C 1회 전송. HID queued 응답 8개 확인. 실제 계산기 반응은 사용자 확인 대기. 시험 후 포트 닫음.
- 사용자 “응. 정상 작동 확인 됐어.”로 계산기에서 클릭 동작 확인. 4방향 이동과 클릭의 기본 HID 검증 완료.
- 다음 단계: S10에 Nordic nRF Connect for Mobile을 설치하여 Custom GATT 알림 구독 후 HID와 동시 동작 확인. 공식 배포 확인: https://play.google.com/store/apps/details?id=no.nordicsemi.android.mcp
